# App icon

`app-icon-source.png` is the supplied master: a glowing blue padlock on a transparent background (1254 × 1254).

Derived assets (regenerate from the master if it changes):

- `app-icon.png` and the iOS `AppIcon.appiconset/icon.png`: 1024 × 1024, opaque, padlock at 72 % of the height on navy `#050D24` (iOS icons may not be transparent).
- Android adaptive icon: `drawable-nodpi/ic_launcher_foreground.png` (padlock at 47 % of the 108 dp layer, inside the 66 dp safe zone), background colour `@color/icon_background` (`#050D24`), and a white silhouette `ic_launcher_monochrome.png` for Android 13+ themed icons.
- `drawable-nodpi/vault_icon.png`: transparent padlock shown on the unlock screen.
